# Instituto Chroma — Prévia editorial V3

**Versão para avaliação da direção, não aprovada para divulgação institucional definitiva.**

## Como abrir
Abra `index.html` em seu navegador, ou configure uma hospedagem estática com a pasta raiz do projeto.

## Conteúdo incluído
- 6 páginas institucionais com navegação responsiva.
- História editorial provisória criada a partir de informações sobre a Chroma.
- Método de aprendizagem documentado nas aulas inaugurais.
- Projeto Aluno Nota 10, projeto pedagógico Nexus Corp e atividades divulgadas publicamente.
- Endereços e canais encontrados nos materiais de aula inaugural e fontes públicas.
- Carrossel inclinado com artes oficiais e imagens conceituais.
- Formulário sem backend: compõe uma mensagem no WhatsApp selecionado para o usuário enviar.

## Ações antes de aprovação
Leia `VALIDACAO_EDITORIAL_V3.md` e `HISTORIA_EDITORA_PROVISORIA.md`. As imagens criadas com IA são simulações e estão identificadas. Não representam instalações, professores ou estudantes reais. Confirmar informações pendentes com a direção antes de publicar em produção.
