PROJETO ALUNO NOTA 10

Um incentivo para seguir acreditando no próprio potencial.

Em ações com escolas públicas, o projeto apresentado pela Chroma utiliza uma avaliação de conhecimentos gerais, com pontuação de 0 a 10, para reconhecer o desempenho estudantil.

Na avaliação de conhecimentos gerais, a pontuação máxima pode oferecer acesso a uma bolsa integral. Outros resultados elegíveis podem receber bolsas parciais, conforme os critérios do regulamento de cada ação.

As bolsas seguem o regulamento de cada ação. Consulte a equipe para conhecer os critérios.
